Homebrew snapshot collected on 2026-10-03: 239 formula entries and
18 cask entries. Formulae include dependencies. Installation alone does
not establish that a program is used. Versions below are installed versions,
not a claim about the newest release.

The snapshot excludes applications installed outside Homebrew, shell/editor
plugins, Mason packages, and project-specific language environments. The
[older Brewfile](../.bootstrap/macOS/Brewfile) is not a lock file for this list.

To inspect changes later, run these read-only commands:

```sh
brew list --formula --versions
brew list --cask --versions
brew leaves
```
